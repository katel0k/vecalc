# Vecalc

## Описание

Это векторный калькулятор, со следующими основными фичами:

1. Возможность вычислять выражения с векторами
2. Динамически вычислять вектора
3. Визуальным отображением векторов

## Компиляция

```bash
npm i
npm run build
```
